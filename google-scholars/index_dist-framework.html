dist-framework: Découverte et Test de Métriques de DistanceDiscovering and Testing Distance Metrics

Thibaut LOMBARD
Lombard Web Services • 2025

RésuméAbstract

Ce dépôt présente dist-framework, un outil expérimental en Python conçu pour découvrir, tester et évaluer de nouvelles métriques de distance et de similarité. Le framework intègre des techniques de fuzzy matching, d'analyse topologique des données (Persistent Homology) et d'apprentissage profond (Triplet Loss). Ce package inclut la documentation théorique et les implémentations de :
1. La "Distance de Fibonacci" : une métrique évaluant la conformité d'une séquence aux propriétés de récurrence de Fibonacci et au nombre d'or (paramètres α et β).
2. Le cadre de "Précision" : un modèle formel utilisant des seuils (R pour les signaux continus, N pour les données discrètes) et une distance θ pour évaluer la correspondance dans des structures variées (documents, vecteurs).

This repository presents dist-framework, an experimental Python tool designed to discover, test, and evaluate new distance and similarity metrics. The framework integrates fuzzy matching techniques, topological data analysis (Persistent Homology), and deep learning (Triplet Loss). This package includes theoretical documentation and implementations of:
1. The "Fibonacci Distance": a metric evaluating a sequence's conformity to Fibonacci recurrence properties and the golden ratio (parameters α and β).
2. The "Precision" framework: a formal model using thresholds (R for continuous signals, N for discrete data) and a distance θ to evaluate correspondence in various structures (documents, vectors).
