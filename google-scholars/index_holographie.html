Transformations géométriques pour la simulation holographique tridimensionnelle

Thibaut LOMBARD

Lombard Web Services

Résumé

Ce document décrit une méthode permettant de simuler le rendu holographique 3D à l'aide d'une seule image source. La technique repose sur l'application de transformations géométriques (rotations et symétries) pour générer un effet de perspective adapté à une forme pyramidale. Les images transformées sont ensuite assemblées dans une mosaïque 2x2.
